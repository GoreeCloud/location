Location data belongs to you. Know what this preview does and does not do.

DATA OWNERSHIP

Private infrastructure

Records are stored in your self-hosted SQLite database. Access requires an account, and device ingestion uses separate revocable tokens.

Public registration, advertising, third-party trackers, and automatic map-provider requests are disabled. Map tiles can be configured from your own tile server.

To remove individual positions, use the API. Database backups and account creation are managed by the server administrator.

DEVELOPMENT PREVIEW

Know the boundaries

Browser location capture requires your permission and a secure context (HTTPS or localhost). It is manual, not a native background-tracking client.

Family circles, push alerts, crash detection, professional emergency dispatch, native apps, and fleet integrations are future work—not active safety services.

Do not use this preview for emergency response or critical real-time monitoring.
